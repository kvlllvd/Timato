# Timato

Локальный таймер-помидор для macOS. Живёт в строке меню, окно висит поверх всех
остальных окон. Два варианта — 25 и 50 минут. После отработанного отрезка сам
включается отдых — 5 минут после 25, 10 минут после 50, — а после отдыха окно
возвращается к выбору. Без сети,
без аккаунтов, без настроек.

## Что нужно

macOS 13 Ventura или новее, Apple Silicon **или** Intel — бандл universal.

## Установка

1. Скачать `Timato.dmg` со страницы
   [Releases](https://github.com/kvlllvd/Timato/releases/latest).
2. Открыть образ, перетащить `Timato.app` в `Applications`.
3. Запустить.

**Первый запуск потребует одного лишнего действия.** Приложение подписано
самодельной (ad-hoc) подписью, без Developer ID: у проекта нет платного
аккаунта разработчика, поэтому нотаризации тоже нет. Всё, что скачано через
браузер, macOS помечает карантином и на первом запуске покажет «Apple не может
проверить приложение на наличие вредоносного ПО».

Кнопки «Открыть» в этом окне на свежих macOS больше нет. Два рабочих способа:

```
xattr -d com.apple.quarantine /Applications/Timato.app     # снять карантин
```

либо: попробовать запустить, получить отказ, затем **Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть**.

**Уведомления.** При первом запуске система спросит разрешение. Если отказать,
звонок всё равно будет звучать — пропадёт только баннер.

## Как пользоваться

- Клик по `25` или `50` — начать отрезок работы. Отдых выбирать не надо: он
  приходит сам после отработанного отрезка — 5 минут после 25 и 10 после 50.
- На экране отсчёта три кнопки. **Finish now** — закончить отрезок сейчас: тот
  же звонок, та же засечка, тот же переход к отдыху. **Pause** — пауза, окно
  уходит в серый. **Stop** — бросить отрезок и вернуться к выбору; засечка при
  этом не ставится. На отдыхе из трёх остаётся один «Stop».
- **Светлая тема** меняет только фон идущей работы и экрана выбора: окно
  светлое, табло и полоса остатка тёмные, свечения в углу нет. Пауза остаётся
  серой, а отдых — зелёным, теми же, что и в тёмной теме: там цвет фона говорит
  о состоянии («время не идёт», «сейчас перерыв»), а не об оформлении.
- Закрыть окно можно в любой момент — **отсчёт продолжит идти**. Вернуть окно
  или выйти — через помидор в строке меню. С клавиатуры: `Cmd+W` закрыть окно,
  `Cmd+H` спрятать, `Cmd+Q` выйти.
- Окно таскается **за любое своё место** — за фон, за табло, за ряд черточек,
  за кнопки — и **с первого же нажатия**: активировать приложение отдельным
  кликом не надо, жмёшь на пилюлю прямо из рабочего окна, держишь и тащишь.
  Окно **прилипает к углам экрана**, доходя до физического края:
  под меню-бар и Док в том числе. Кнопка отличает перенос от нажатия по мыши:
  увели её — это перенос, отпустили на месте — это клик. У краёв пилюля
  выпрямляет углы: скругление остаётся только у тех, что лежат внутри экрана, —
  прижатый угол со скруглением оставлял бы под собой щель.
- Засечки под цифрами — сколько отрезков работы закрыто. Штрих читается как час,
  половина штриха — как полчаса, то есть один отрезок в 25 минут. Поначалу
  черточек четыре, во всю ширину окна; закрасились все четыре — ряд делится
  вдвое мельче и справа встают ещё четыре, то есть восемь часов в ряду.
  Заполнился весь ряд — следующий отрезок начинает его заново, снова с четырёх.
- В режиме `Adaptive` (включается в меню помидора) трекер **сворачивается** до
  табло и полосы остатка, пока идёт отрезок 25 / 50 и курсора на окне нет:
  кнопки уезжают за правый край, окно занимает 136 точек вместо 294. Уходит он
  не сразу, а через 5 секунд — рука с мышью проходит над окном чаще, чем
  оставляет его насовсем. Курсор вернулся — полный вид возвращается сразу, без
  всякой паузы. Отдых, пауза и экран выбора всегда в полном виде.

**Меню помидора в строке меню.** Семь пунктов:

| Пункт | Что делает |
|---|---|
| `Summary — N h` | сколько наработано за сеанс. Клик по нему **возвращает окно** — отдельного «Show» в меню нет |
| `Mute` / `Unmute` | глушит звонок окончания. Пункт называет действие: при включённом звуке это `Mute`, при выключенном — `Unmute`. Баннер уведомления остаётся в любом случае |
| `Size` | вложенный список из двух. `Adaptive` — идущий отрезок 25 / 50 без курсора сворачивается до табло и полосы (136 точек) через 5 секунд после того, как курсор ушёл; под курсором разворачивается обратно сразу. `Full` — вид по умолчанию: полная пилюля всегда, в любом состоянии |
| `Theme` | вложенный список из трёх: `Light`, `Dark`, `System`. Выбор сохраняется между запусками; при `System` тема идёт за системной и переключается вместе с ней |
| `Guide` | окно с коротким объяснением всех кнопок, в том числе неочевидных |
| `Reset` | обнуляет и ряд засечек, и итог. Идущий отсчёт при этом не трогает |
| `Quit` | выход |

**Две вещи, которые сами не находятся** — они и описаны в «Guide»:

- клик по **ряду засечек** подменяет `25` / `50` кнопкой сброса прогресса;
  повторный клик возвращает варианты, ничего не тронув;
- клик по **табло со временем** перекрашивает свечение в углу: зелёное →
  фиолетовое → синее → красное. Только внешний вид, на отсчёт не влияет.

**Счёт живёт до выхода.** Засечки, `Summary`, выключенный звук и выбранный вид
трекера держатся в памяти: пока приложение запущено — хоть неделю, — засечки копятся, после `Quit`
всё начинается с нуля и звук снова включён. На диск сохраняется только положение окна. Истории сессий в первой версии нет осознанно.

## Сборка из исходников

Нужны только Command Line Tools (`xcode-select --install`). Полный Xcode **не нужен**
и не подойдёт как требование: интерфейс сознательно написан на AppKit, потому что
макрос-атрибуты SwiftUI (`@State` и прочие) собираются только плагином из Xcode.

```
./build.sh          # Timato.app + dist/Timato.dmg
./build.sh --app    # только Timato.app, без упаковки
./run-tests.sh      # полная сборка + все автотесты по acceptance criteria
```

`build.sh` собирает исходники **дважды** — под arm64 и под x86_64 — и склеивает
срезы `lipo`. Перед публикацией бандла сборка проверяет, что в исполняемом файле
есть оба: бандл с одним arm64 у автора выглядит совершенно рабочим и молча не
запускается на Intel-машине.

`run-tests.sh` всегда пересобирает приложение целиком и падает, если хоть один
исходник не компилируется. Сборка публикует бандл только целиком: упавшая
компиляция не оставляет огрызок `.app`, который выглядел бы готовым.

Отдельно прогон собирает копию из **одних отслеживаемых git файлов** — то, что
получит `git clone`. Это ловит забытый `git add`: файл лежит в рабочем дереве, у
автора всё зелено, а склонированный репозиторий не собирается.

При разработке приложение запускают десятками раз подряд, и звонок окончания
бьёт по ушам из фона. Переменная окружения `TIMATO_MUTE=1` открывает приложение
с уже выключенным звуком:

```
TIMATO_MUTE=1 build/Timato.app/Contents/MacOS/Timato
```

Обычный запуск (двойным кликом, `open`) переменной не видит — там звук включён.

Кроме проверок ядра прогон поднимает **настоящее окно** и нажимает его кнопки:
`Tests/LiveInterfaceCheck.swift` собирается из тех же `Sources` со своим `@main`
(флаг `-DLIVE_CHECK`) внутри копии бандла и читает, что оказалось на экране, —
время на табло, какой экран показан, цвет фона, засечки. Внутри бандла потому,
что без bundle identity не проверить доставку уведомления.

## Как устроено

| Файл | Что внутри |
|---|---|
| `Sources/TimerEngine.swift` | ядро: состояния, отсчёт, помидоро, чистые функции для тестов |
| `Sources/TimerWindowController.swift` | окно, два экрана, табло, полоса, засечки, прилипание к углу |
| `Sources/Notifier.swift` | звонок, баннер, текст про просрочку, флаг `Mute` |
| `Sources/App.swift` | точка входа, меню помидора, главное меню для сочетаний клавиш |
| `Sources/GuideWindowController.swift` | окно «Guide»: высота считается по содержимому при ширине 500 |
| `Sources/TomatoIcon.swift` | иконка из `Resources/Tomato.png` — и для бандла, и для строки меню |
| `Sources/Theme.swift` | тема оформления: `Light` / `Dark` / `System`, хранение выбора и оповещение окон |
| `Sources/DisplayFont.swift` | регистрация `NothingFont5x7.otf` из бандла до сборки интерфейса |
| `Icon/MakeIcon.swift` | генератор `.iconset` при сборке |
| `build.sh` | компиляция обоих срезов и склейка `lipo`, бандл, ad-hoc подпись, проверка целостности, DMG |
| `Tests/EngineTests.swift` | проверки ядра: отсчёт, пауза, звонок, помидоро |
| `Tests/LiveInterfaceCheck.swift` | проверки живого окна: нажатия кнопок и что оказалось на экране |
| `run-tests.sh` | автотесты по acceptance criteria |

**Время считается по монотонным часам** (`mach_continuous_time`), а не по
`Date` и не вычитанием секунды на тик. Настенное время не годится: шаговая
коррекция по NTP, ручная правка даты или dual-boot сдвигают дедлайн, и таймер
звонит не вовремя. Монотонный источник ещё и продолжает идти во сне, поэтому
проспанный дедлайн не теряется — звонок прозвучит при пробуждении, а в
уведомлении будет честно написано, сколько времени назад таймер закончился.


## Чего в первой версии нет

Произвольное время вводом, глобальный хоткей, история сессий и статистика,
редактируемые варианты, подпись Developer ID и нотаризация.

Порог macOS остаётся 13.0 и ниже не опускается: до 13.0 Swift подцепляет шимы
совместимости, а в Command Line Tools они лежат только под arm64 — x86_64-срез с
таким порогом не линкуется. Понизить порог и остаться universal одновременно
нельзя; выбран universal.
